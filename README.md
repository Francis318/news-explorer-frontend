# News Explorer - Frontend

Un proyecto web interactivo que permite a los usuarios buscar noticias recientes sobre cualquier tema, leer fragmentos de los artículos y guardar sus favoritos en su cuenta personal.

Este repositorio contiene exclusivamente el lado del cliente (Frontend) de la aplicación, diseñado con un enfoque en la fidelidad visual, la responsividad y la experiencia de usuario.

## 🚀 Características Principales

- **Búsqueda de Noticias:** Integración con un campo de búsqueda dinámico para encontrar artículos en tiempo real.
- **Diseño Responsivo:** Interfaz adaptable a múltiples resoluciones (Desktop, Tablet y Móvil) garantizando una experiencia fluida en cualquier dispositivo.
- **Fidelidad al Diseño:** Maquetación pixel-perfect basada en un diseño profesional de Figma.
- **Tarjetas Interactivas:** Visualización atractiva de los resultados de búsqueda con opciones para interactuar (guardar/eliminar).

## 🛠️ Tecnologías Utilizadas

- **React.js:** Biblioteca principal para la construcción de la interfaz de usuario basada en componentes (Header, Navigation, SearchForm, Footer, etc.).
- **CSS3:** Estilos estructurados e independientes para cada componente.
- **Metodología BEM (Block Element Modifier):** Utilizada para mantener un código CSS limpio, escalable y evitar colisiones de estilos.
- **Flexbox & Positioning:** Uso avanzado de CSS para alineación precisa de elementos y superposición de componentes (como el botón de búsqueda integrado en la barra de texto).

## 📂 Estructura del Proyecto

El proyecto está organizado de forma modular, donde cada sección principal de la página tiene su propio archivo JSX y su correspondiente hoja de estilos CSS:

- `Header` y `Navigation`: Barra de navegación superior transparente y adaptable.
- `SearchForm` y `Main`: Título destacado y el formulario central de búsqueda.
- `About`: Sección informativa del autor de la aplicación.
- `Footer`: Pie de página con enlaces a redes sociales y derechos de autor.
